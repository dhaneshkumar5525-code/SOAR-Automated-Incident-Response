# SOAR-Automated-Incident-Response
Designed and implemented an end-to-end SOAR pipeline using Python, Tines, VirusTotal, URLScan.io, and Jira to automate security alert enrichment, classification, and incident response. The workflow analyzes IOCs, calculates risk scores, maps MITRE ATT&amp;CK techniques, and automatically creates Jira tickets with detailed analyst comment on the alert
